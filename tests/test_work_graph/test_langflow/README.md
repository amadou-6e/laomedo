# Frozen Langflow graph boundary

Runtime admission accepts the pinned Langflow umbrella or base application,
requires every installed app distribution and lfx to match, and rejects before
graph construction or run reservation. Metadata controls run in ordinary
unittest discovery. Real graph controls require the pinned runtime and use an
owned graph; they do not authenticate a user, launch a provider or spend a model
turn. Their skip is explicit when the runtime is absent.

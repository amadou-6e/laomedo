# Private-directory admission and permission controls

The suite belongs to `host/private_state`: legacy SIWC permission effects and
strict Agent credential-directory admission share mechanisms, not policy.
`test_permissions.py` protects exact legacy command arguments and exception
translation, strict path admission, verification without repairing existing
leaves, and private deadline projections. It uses no credentials or Docker.
Internal command/descriptor seams are supporting controls; they do not establish
real credential-copy or provider acceptance. Production callers import the
canonical classes and functions; no compatibility module is installed.

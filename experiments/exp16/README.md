# EXP-16: mock Work Graph dispatch binding

This credential-free experiment composes the installed Work Graph snapshot model,
the existing synthetic durable run store and the EXP-05 evidence store. It does
not implement a production launch adapter or call a model. The prospective
[protocol](https://github.com/amadou-6e/specs/blob/docs/46/projects/laomedo/experiments/work-graph-dispatch-binding/protocol.md)
was committed before the test data. `corpus.json` contains synthetic GitHub
response pages generated by `fixtures.py`; `cases.json` selects source,
freshness, grant and mock-runner variants; `oracle.json` was hand-written before
execution. The probe reads those frozen JSON files, not the generator.

Run the probe with an installed Laomedo wheel in a fresh environment and a fresh
output directory outside Git. From the Laomedo checkout, use the installed
environment's Python in isolated mode:

```powershell
& '<private-venv>\Scripts\python.exe' -I experiments\exp16\probe.py --output-dir '<private-output-dir>'
```

The probe loads the EXP-05 evidence store by file path without adding the
checkout to Python's import path, so `laomedo` resolves from the installed
wheel. Every case has an isolated SQLite store. Rejected cases must leave its
run and dispatch counters at zero. Accepted cases keep immutable graph and
input refs, a synthetic grant, run/trace identities and raw mock events. The
fixture grant checks binding and expiry fields only; it is not a real
authorization grant. EXP-03's missing native component attestation and the
real adapter refusal remain with [#77](https://github.com/amadou-6e/laomedo/issues/77).

The [sanitized result](result.json) records 20 passing cases and each counter,
snapshot and binding check. Its private installed-wheel path is replaced with
a placeholder; the raw result and SQLite artifacts stay in the disposable
output directory. The fixtures and oracle were written by the implementation
author in separate commits from the result, not by an independent second party.
This is a mock boundary result only and does not grant real dispatch authority.

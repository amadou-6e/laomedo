## Cases and handwritten expectations

| Case | Expected route | External publication |
| --- | --- | --- |
| Valid success, complete native trace and verified pushed artifact | Success | Exactly one draft PR, read back against frozen bytes |
| Valid task failure | Failure | None |
| Invalid submission after bounded output correction | Rejection | None |
| Same-request precheck rejection then correction | Success only after accepted output | Same single approved draft budget, if allocated to this case |

Allocate cases to the approved cap before execution. If the cap cannot cover a
case, mark it unexecuted; synthetic results do not replace live acceptance.
No automatic continuation after external effects; same-request correction uses
the native precheck, not repetition of a GitHub write.

## Trusted controller and evidence

The agent gets only its provider connection and scoped mediated capability.
The GitHub token stays on the host. One finite controller-owned lease covers
execution, validation and publication. Deadline, repository, base, head and
publisher payload are not supplied by graph data.

Before publication, retain exact native turn/item identities, terminal status,
command completions, the final answer from the host trace, a working-file
snapshot and verified executor/controller cleanup. Missing or ambiguous closure
stays unknown. This establishes execution evidence availability, not truthful
task success; the downstream contract and verified artifact are separate gates.

For each live submission, reserve and persist a ledger entry before turn/start;
timeouts and rejected submissions count. Record native precheck calls and
continuations separately. Preserve partial evidence and every failed attempt.

Write a sanitized machine report with source/graph/skill/requirements pins,
run/invocation/thread/trace identities, contract outcome, route, effect identity,
publication result and independently read-back PR head/base/content. Scan exported
evidence and published bytes for provider login material and runner/GitHub tokens
without printing values or publishing credential hashes. Raw traces stay private.

## Stops and cleanup

Stop at the cap/deadline, lost/revoked connection, changed frozen inputs,
unverified cleanup, unclosed command/tool, failed output gate or uncertain write.
Never resend an unknown write. Retain its durable intent/receipt for read-only
reconciliation. No issue closure, PR merge, workflow-file mutation or broad API
permission is part of this campaign.

Leave approved test branches and draft PRs for inspection unless cleanup is
separately authorized. Record container/lease cleanup; do not delete another
run's state. Amend this protocol prospectively and obtain review before changing
an executed case. This preparatory commit uses zero model turns and no credentials.

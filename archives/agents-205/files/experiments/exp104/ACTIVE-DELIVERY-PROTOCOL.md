before PATCH, and malformed/unbound PR read must be refused without a provider
request. A changed credential generation or completed run must prevent a new
freeze/push. After success, revoke this run and require a fresh write identity
to be denied with fake-provider count unchanged. Never retry unknown effects.
Poll verification for at most 30 seconds, then report incomplete without a new
attempt. Each fake push/PR mutation has a unique fixed effect identity. Record
the exact source and fixture hashes, operation order, provider attempts and
authoritative final head/body hash. No new phase or repeated case after failure.

# Actual Skill browser checks

These are historical task harnesses for the Windows/headless Edge environment
recorded in the parent evidence. They operate actual loopback services, registry
bytes and component metadata; they provide no fake provider or HTTP responses.
They require the task-private runtime metadata and browser state, which are not
archived. Configure a separate private runtime using the maintained Skill guides
before adapting these paths. Never copy credentials, browser state or databases
into this archive, and never make production CI fetch or require these scripts.

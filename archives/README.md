# Experiment archives

This branch retains investigations separately from production code. The current
code starts from accepted `develop`; do not merge this branch wholesale back.

`examples/skill-operations/` retains the complete former Skill operation example
at the source revision recorded in its `PROVENANCE.json`. Every original file is
byte-preserved. Relative links and runnable paths inside those historical files
describe their original checkout. They are not supported setup commands here.
Use the maintained Skill walkthrough on the production branch for current setup.

Archive publication does not rerun or accept the recorded model campaign.

`experiments/exp08/` retains the original exact-byte Skill delivery campaign.
Its byte-preserved source/evidence and provenance remain historical. Current
production assertions live under `tests/skills/workspace`; they do not import
this archive or run an Agent. Other experiment families are deferred.

# Historical controls

Historical campaign sources are not launcher examples or present acceptance
proof. Their original observations and exact source versions remain on `exp`.
The deferred Agent/GitHub sources still needed by selected internal controls stay
inventoried in `tools/migrations/retained-shared-callers.json`; this is not permission
to add experiments to production or execute a historical native entry point.

Private procedural Git helpers and the old native provider paths were retired.
Do not run those probes directly against the current package. Explicit internal
controls may load only an inventoried, hash-checked temporary copy through
`tests/support/retained.py`. Its declared import/dependency rewrites preserve the
remaining AST; removed process helpers refuse. It is not a runtime compatibility
facade or a model-backed verification path.

Post-format source hashes establish the admitted copy's identity only. They do
not validate older LIVE-MANIFEST pins or establish historical seal compatibility.
EXP100's older source pin cannot be inferred from the formatted copy;
EXP104_managed remains an unexecuted candidate unless separate real evidence is
recorded. Other legacy seal relationships remain unestablished. Never relabel or
regenerate an old observation as evidence for a new implementation.

# GitHub user stories

Stories and their visuals belong to the owning module:

- [Issue user stories](issues/user-stories.md): selection, inspection and existing-target operations.
- [Pull-request user stories](pull-requests/user-stories.md): selection, inspection,
  Agent feedback and a proposed creation workflow.

The original combined story IDs remain below as navigation references. Acceptance
criteria, implementation status and visual provenance live in the module pages.

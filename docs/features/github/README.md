# GitHub

GitHub nodes select repository work and perform scoped operations while the
host keeps provider credentials outside the agent runtime.

Start with [connect your local app to GitHub](connection.md), then follow the
[Issue walkthrough](issues/walkthrough.md) or [PR walkthrough](pull-requests/walkthrough.md).
Both begin with real read-only selection and inspection. Their optional operation
steps state the additional host authorization required before any write.

- [Issues](issues/README.md): issue selection, inspection, operations and user stories.
- [Pull requests](pull-requests/README.md): PR selection, inspection, Agent feedback,
  user stories and the proposed creation workflow.
- [Shared architecture](architecture.md): host authority and transport ownership.
- [User-story index](user-stories.md): navigation across both modules.

Each module owns its documentation and visual assets. Existing examples remain
the detailed setup guides; historical evidence is not acceptance of the current head.

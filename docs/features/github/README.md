# GitHub

[User stories and visuals](user-stories.md) describe the implemented experience
and clearly labelled proposals.

GitHub nodes select repository work and perform scoped operations while the
host keeps provider credentials outside the agent runtime.

- [Architecture](architecture.md): node, client, contract, gateway and transport ownership.
- [Issue node guide](../../../examples/github-issue/README.md): discovery,
  selection, outputs, operations and deployment requirements.
- [Pull-request node guide](../../../examples/github-pr/README.md): feedback
  operations through the existing Agent and known limitations.
- [Original-Agent PR example](../../../examples/github-pr/original-agent/README.md):
  recorded real workflow and evidence boundaries.

These existing examples remain the detailed guides; historical evidence is not
rewritten or treated as validation of the current head. Governing issue contracts
live in the [canonical specifications](https://github.com/amadou-6e/specs/tree/main/projects/laomedo/subsystems/issue-integration).
